# sample_files

Stand-in PDFs so every example builds out of the box:

- `sample_resume.pdf`: a one-page placeholder resume, used by the packet (`\resumefile` in the form)
- `sample_cv.pdf`: a one-page placeholder CV, used by the packet (`\cvfile` in the form)
- `sample_article.pdf`, `sample_chapter.pdf`: placeholder writing samples

Replace them with your own PDFs (or point the form at files anywhere else).
The `.tex` sources are here only so the placeholders can be rebuilt with `make sample-files`.
